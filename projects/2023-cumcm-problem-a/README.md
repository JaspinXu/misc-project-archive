# 2023 全国大学生数学建模竞赛 A 题

本目录归档当时针对“定日镜场的优化设计”所做的建模工作。主要思路包括太阳位置与光线向量计算、阴影遮挡和余弦效率估计、蒙特卡洛采样，以及使用粒子群算法搜索镜场参数。

## 主要文件

- `2023国赛A题论文.docx`：最终论文文档。
- `支撑材料/`：较完整的 MATLAB 程序、MAT 数据和结果表，包含 `q1.m`、`q2.m`、`q3.m` 等入口或阶段性脚本。
- `附件.xlsx`：赛题附件数据。
- `新建文件夹/`、`新建文件夹(1)/`：比赛期间留下的中间版本，出于归档目的原样保留。
- 其他 PDF：竞赛说明及当时查阅的参考文献。

## 已知限制

- MATLAB 版本和工具箱版本没有记录。
- 多个脚本依赖同目录下的 `.mat` 文件，并带有明显的竞赛期间试验痕迹；建议从 `支撑材料/` 开始阅读。
- 参考论文和竞赛文件均属于第三方材料，版权归各自作者或发布机构所有。
